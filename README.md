# 📖 Overview

This repository documents the complete evolution of our **Semester 5 Mini Project**.

This project began with a lot of pondering regarding sensor selections, system architecture and various other things. We created a custom-made Magnetic Switch Sensor in Wokwi for Simulation

---

# 🚀 Project Evolution

| Version | Platform | Major Contribution |
|----------|----------|--------------------|
| 🟢 Base Simulation | ESP32 Simulation on Wokwi | Door Security system using OOPs,FSM and interrupts. Along with Door States it also explored Door Transitions |
| 🔵 Hardware Implementation | STM32, ESP32 and Rpi based Home Security System | Starts from the Base Simulation to integrating MIT Bluetooth App, Firebase and Rpi based Face Detection |
| 🟣 Advanced Simulation | ESP32 Simulation on Wokwi | More Robust OOPs Architecture (Class into class) |

---

- Intruder Detection using PIR sensor
